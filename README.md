# World Football V5

Nova versão do protótipo:
- Publicação pública sem conta
- Aprovação/rejeição pelo administrador
- Pesquisa por equipa/competição
- Filtro por país, competição e data
- Página individual de cada jogo
- Contagem de visualizações
- Logos opcionais das equipas por URL
- Estatísticas no painel administrativo

## Executar
1. Instale Node.js.
2. Abra esta pasta no terminal.
3. Execute `npm install`
4. Execute `npm start`
5. Abra `http://localhost:3000`
